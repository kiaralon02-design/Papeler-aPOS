# Papelería Escolar POS

# Descripción del proyecto
El proyecto consiste en desarrollar un sistema de punto de venta para una papelería escolar, utilizando el lenguaje de programación java.
El sistema permitirá registrar productos, consultar el inventario, registrar clientes, realizar ventas y generar comprobantes de pago.

# Tipos de productos

- Productos por unidad: cuadernos, lápices, lapiceros y borradores.
- Productos por peso: materiales que se venden según su peso.
